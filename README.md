<p align="center"><strong>A narrative terminal game.</strong></p>

A terminal-based narrative game about how you choose to spend your time. Built with the [ember](https://github.com/matthewjberger/ember) engine.

## Quickstart

```bash
just run
```

## Simulate

Run the game in auto-play mode for testing:

```bash
just simulate
```

## Prerequisites

* [Rust](https://www.rust-lang.org/tools/install)
* [just](https://github.com/casey/just)
